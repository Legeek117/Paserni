🔧 Test de la Connexion Admin

📋 Instructions de Test :

  1. Ouvrez votre site en mode développement
  2. Allez sur /admin/login
  3. Connectez-vous avec vos identifiants admin
  4. Vérifiez que vous restez connecté

🔍 Vérifications à faire :

  • ✅ La page de login s'affiche correctement
  • ✅ Vous pouvez saisir email et mot de passe
  • ✅ Après connexion, vous accédez au dashboard admin
  • ✅ Vous ne êtes pas déconnecté immédiatement
  • ✅ Le timer de session s'affiche (24h)

✅ Corrections Appliquées :

  • RequireAdmin.tsx : Vérification de session avant vérification d'expiration
  • SessionTimer.tsx : Ne se déclenche pas si la session n'existe pas
  • AdminLogin.tsx : Définit l'expiration de session immédiatement après connexion

🛠️ Si le problème persiste :

  1. Videz le cache du navigateur (Ctrl+F5)
  2. Vérifiez la console pour d'éventuelles erreurs
  3. Vérifiez que votre compte admin existe dans Supabase
  4. Vérifiez la configuration Supabase dans .env
