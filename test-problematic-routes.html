💡 Solutions recommandées

Si les tests montrent des erreurs 404 :
1. Vérifier que le fichier _redirects est présent dans dist/
2. Vérifier que la règle /* /index.html 200 est présente
3. Redéployer sur Netlify
4. Vider le cache du navigateur
Si les tests montrent du code source :
1. Le problème vient de la configuration de redirection
2. Vérifier que netlify.toml est correct
3. Vérifier que _redirects est dans le bon format
4. Forcer un redéploiement complet
